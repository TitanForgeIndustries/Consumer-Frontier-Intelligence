# Local data and reproducibility

Run commands from the repository root in an environment with the dependencies needed by that experiment. Experiment scripts use `CFI_DATA_ROOT` for their default dataset, model/cache, and result paths. If unset, the root is the ignored `.cfi-data/` directory in this checkout. To store data on another volume, set `CFI_DATA_ROOT` to an absolute directory **outside Git** before starting Python, or pass explicit `--model`, `--dataset`, `--corpus`, and `--output` paths as applicable. Set `HF_HOME` under the same root if the Hugging Face cache should live there too. The `.cfi-data/`, `.venv/`, `experiments/`, and `results/` directories are ignored by Git; review staged files before publishing. The original CFI v0 train/inference CLIs require explicit corpus/output/checkpoint paths and do not load Qwen.

Historical experiment documents use `CFI_DATA_ROOT/Results/<run>` and `CFI_DATA_ROOT/Datasets/<dataset>` as **logical artifact locations under the original run's external data root**, not as GitHub links or assertions that another checkout contains these files. Reproduction commands using `.cfi-data/` write a *new local run*; they do not relocate or alter old results. Explicit `.cfi-data/` CLI arguments are checkout-local even if `CFI_DATA_ROOT` is set; replace those arguments to place the reproduction on an external volume. The pinned upstream source, raw artifact names, hashes, exact measurements, failures, and historical run conditions in each record remain authoritative. Never overwrite a completed run to hide an implementation failure.

For EXP-0010/0011, download the pinned `data/tinyshakespeare/input.txt` from the source link in [EXP-0010](experiments/EXP-0010-cfi-v0-smoke.md) to `.cfi-data/Datasets/CFI-EXP-0010-TinyShakespeare/input.txt`, verify SHA-256 `86c4e6aa9db7c042ec79f339dcb96d42b0075e16b8fc2e86bf0ca57e2dc565ed`, and run a documented command with a **new** output directory. The published repo does not include corpora, downloaded Qwen weights, result summaries, or checkpoints. Earlier Qwen experiments require the specified base snapshot or an explicit `--model` path; only their auxiliary predictors were trained, not Qwen3-4B-Base. None of those Qwen experiments is the independent code-writing CFI model.
