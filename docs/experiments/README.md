# Experiments

This directory contains detailed records of individual research experiments.

Use a consistent naming scheme such as `EXP-0001-short-name.md`.

Each experiment should record:

- Hypothesis
- Motivation
- Method or architecture
- Hardware and software environment
- Dataset or evaluation set
- Training configuration
- Inference configuration
- Resource usage
- Benchmarks
- Results
- Failure modes
- Interpretation
- Next experiment

Keep raw outputs, checkpoints, and large datasets outside Git unless there is a deliberate reason to version them.
