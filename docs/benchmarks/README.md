# Benchmarks

This directory defines the evaluation framework for Consumer Frontier Intelligence.

The project should measure both capability and efficiency.

## Core categories

- Reasoning
- Coding
- General language ability
- Memory and retrieval
- Adaptation and learning
- Tool use
- Inference efficiency
- Hardware resource usage

## Resource measurements

Where practical, record:

- Parameter count
- Active parameters per token
- VRAM usage
- System RAM usage
- Tokens per second
- Latency
- Training compute
- Inference compute
- Energy consumption

Benchmark scores should include enough context to understand the model, evaluation setup, and resource budget.
