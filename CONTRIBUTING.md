# Contributing

Thank you for your interest in Consumer Frontier Intelligence.

This is an open research project focused on improving AI capability per unit of computation and memory, with consumer hardware as a design constraint.

## Ways to contribute

Contributions can include research ideas, testable hypotheses, reproducible experiments, architecture prototypes, benchmark implementations, performance measurements, bug fixes, documentation, and technical literature reviews.

## Before contributing

For substantial changes, open an issue or discussion first so research direction can be coordinated. Experimental results are especially valuable when another researcher can reproduce them.

## Research contributions

For experiments, document the hypothesis, method, hardware and software environment, data or evaluation set, training and inference settings, resource usage, results, failure modes, interpretation, and next steps.

Negative results are welcome. A failed hypothesis can be useful when it is documented clearly.

## Code standards

Keep implementations reproducible, modular, and documented where behavior is not obvious. Add tests where practical. Treat resource usage and reproducibility as first-class measurements rather than optimizing only for benchmark scores.

## Pull requests

Pull requests should explain what changed, why it changed, what was tested, and whether the change affects research results or reproducibility. Do not present unverified performance claims as established results.
